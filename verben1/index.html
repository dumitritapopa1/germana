Rădăcina (Stamm) = infinitiv fără -en. Dacă rădăcina se termină în -t, -d, -fn, -gn… → se inserează -e- (arbeitet, redest, öffnest). Dacă se termină în -s, -ß, -z, -tz → la «du» dispare -s- (du heißt, du tanzt).

1.2 Marcus’ Tag. Ergänzen Sie die Verben.Scrie verbul din paranteză la forma corectă (Präsens). Atenție la verbele care schimbă vocala! Poți scrie și ae în loc de ä. Dacă greșești, vezi explicația.

✅ Reminder – verbe cu schimbare de vocală (du / er-sie-es)

e → i / ie: essen → isst · geben → gibt · sprechen → spricht · nehmen → nimmt · sehen → sieht · lesen → liest · treffen → trifft · helfen → hilft · vergessen → vergisst

a → ä: fahren → fährt · schlafen → schläft · laufen → läuft · anfangen → fängt … an · tragen → trägt · waschen → wäscht

Celelalte persoane (ich, wir, ihr, sie) sunt regulate.
