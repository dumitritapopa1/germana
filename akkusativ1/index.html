Akkusativ

1.1 Übersetzen Sie die Verben (alle verlangen den Akkusativ!)Tradu verbele (NU uita: toate cer acuzativul). Trage varianta românească lângă verbul german sau atinge-o, apoi atinge căsuța.

⚠ Reminder: Akkusativ – se schimbă DOAR masculinul!
der (masc.)das (neutru)die (fem.)die (plural)
Nominativder / ein / keindas / ein / keindie / eine / keinedie / – / keine
Akkusativden / einen / keinendas / ein / keindie / eine / keinedie / – / keine
Masculinul primește -en (den, einen, keinen). Neutrul, femininul și pluralul rămân neschimbate.
